ShopLink ERP + Commerce

Your physical shops, product inventory and customer marketplace in one connected project.

1. Start on Windows

  1. Install Node.js 24 or newer.
  2. Extract the entire ZIP to a writable folder, such as C:\Projects\ShopLink-ERP-Commerce.
  3. Double-click START-WINDOWS.bat. Keep the console open.
  4. Open http://localhost:3000.

The app is already built. No dependency installation, ChatGPT account, Cloudflare account or separate database setup is needed for this first run.

2. Create your shop and publish an item

Open ERP signup. Enter your profile and shop information. In Inventory → Add product, enter the SKU, variant, price, description and stock. Upload up to eight images, enable Publish to online catalog and save.

3. Shop as a customer

Open customer signup. Create a customer profile, add products to the bag and place a cash-on-delivery order. Orders from different shops are separated automatically.

4. Prepare and ship

In the ERP, open Sales & orders → Online. Click the order number for item variants, quantities, phone and address. Process the order, mark it shipped with optional courier/tracking details, then complete it after delivery. Customers see updates under Orders.

Source code and development

Frontend: app/. API: server/. Stock and role rules: lib/. Resources: components/, vendor/, public/. Ready-to-run build: dist/.

npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm build
node server/index.mjs

Use pnpm dev for editing with hot reload. Read docs/WINDOWS_SETUP.md for complete instructions, docs/API.md for API examples, and docs/ARCHITECTURE.md for the source map. A Postman collection is included.

Keep your data

Accounts, records and uploaded images are created under data/. Stop the server before copying this whole folder for backup. Do not delete it when updating the source.

Project scope: this is a local project implementation. It includes real local accounts and a connected marketplace, but not live card processing, courier booking, email verification/recovery, full accounting or production certification. Delivery is free in this version. The earlier hosted source is included under hosted-source-reference/; it is separate from the local app. Hosted records are not included.
